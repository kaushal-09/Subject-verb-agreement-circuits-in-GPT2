# Subject-verb agreement circuits in GPT-2

Code for the term paper *Small Circuits, Narrow Competence: Agreement Attraction
Resists Circuit Compression and Model Scale in GPT-2*.

It finds the attention heads most responsible for subject-verb agreement, then tests
whether that circuit still works on **agreement attraction**, where a noun of the
wrong number sits between the subject and the verb, as in *the key to the cabinets
is*. It does not, in either GPT-2 Small or GPT-2 Medium.

## Setup

    pip install -r requirements.txt

## Running, in this order

    python run_experiment.py --model gpt2
    python run_experiment.py --model gpt2-medium --device cuda
    python compare_circuits.py results/gpt2 results/gpt2-medium
    python make_figures.py

GPT-2 Small runs on CPU in a few minutes. The committed results came from a
GTX 1660 Ti.

## What each file does

| File | Purpose | When you need it |
|---|---|---|
| `run_experiment.py` | **Main entry point.** Loads one model, builds the stimuli, runs averaged activation patching, picks the top 8.33% of heads as the circuit, then scores that circuit under mean-ablation and zero-ablation. | Run once per model. Everything else reads its output. |
| `compare_circuits.py` | Compares two models' patching effects. Produces the depth profile and the "heads carrying 80% of the effect" figures quoted in the paper. | After both models have been run. |
| `make_figures.py` | Draws all plots and writes a LaTeX table file into `figures/`. | Last, once results exist. |
| `src/dataset.py` | Builds the 130 minimal pairs across six conditions, and the 30 clean/corrupted patching pairs. Seeded, so it is deterministic. | Edit here to change or extend the stimuli. |
| `src/circuit_analysis.py` | The actual method. Logit differences, per-head activation patching, top-k selection, mean activations, and circuit-restricted evaluation. | Edit here to change the discovery or ablation procedure. |
| `results/` | Committed output. Per-condition accuracies, per-item logit differences, raw per-head effects, and the selected circuit for each model. | Read this if you want the paper's numbers without rerunning anything. |

## Notes

`figures/` is gitignored because everything in it is regenerated by
`make_figures.py`. Four of its plots appear in the paper, namely the two heatmaps,
the accuracy comparison and the logit-difference distributions. The depth profile
and ablation comparison are also generated and are the visual form of numbers the
paper quotes in the text.

`CIRCUIT_FRACTION` in `run_experiment.py` fixes circuit size as a proportion of
total heads rather than a fixed count, so GPT-2 Small gets 12 heads of 144 and
GPT-2 Medium gets 32 of 384. A fixed count would have given the larger model a
circuit less than a third as dense, which would confound scale with circuit size.

Mean-ablation is the primary metric and zero-ablation is the robustness check.
Zeroing over ninety percent of heads pushes the residual stream far outside the
training distribution, and its results proved sensitive to stimulus-set size where
mean-ablation's did not.
